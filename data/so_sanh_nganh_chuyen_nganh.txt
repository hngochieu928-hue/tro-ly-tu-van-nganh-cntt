## 3. SO SÁNH CẶP ĐÔI

### 3.1. Công nghệ phần mềm vs Khoa học dữ liệu
- CNPM: tập trung vào **xây dựng sản phẩm phần mềm**; KHDL: tập trung vào **khai thác dữ liệu để ra quyết định**.
- CNPM cần **tư duy hệ thống + logic lập trình**; KHDL cần **tư duy phân tích + toán thống kê**.
- Nếu thích **code sản phẩm** → CNPM. Nếu thích **code để phân tích** → KHDL.

### 3.2. Công nghệ phần mềm vs An ninh mạng
- CNPM: **tạo ra** phần mềm; ATTT: **bảo vệ** phần mềm/hệ thống.
- CNPM học nhiều về kiến trúc, framework; ATTT học nhiều về mạng, mã hóa, tấn công – phòng thủ.
- Nếu thích **xây dựng** → CNPM. Nếu thích **bảo vệ, điều tra** → ATTT.

### 3.3. Hệ thống TMĐT vs Khoa học dữ liệu
- TMĐT: **công nghệ + kinh doanh online**; KHDL: **công nghệ + dữ liệu + AI**.
- TMĐT cần hiểu **quy trình bán hàng, thanh toán, logistics**; KHDL cần hiểu **thống kê, mô hình dự báo**.
- Nếu thích **kinh doanh** → TMĐT. Nếu thích **phân tích** → KHDL.

### 3.4. Hệ thống TMĐT vs An ninh mạng
- TMĐT: **xây dựng và vận hành** hệ thống bán hàng; ATTT: **bảo vệ** hệ thống khỏi tấn công.
- TMĐT thiên về **nghiệp vụ + phát triển**; ATTT thiên về **kỹ thuật + phòng thủ**.

### 3.5. An ninh mạng vs Khoa học dữ liệu
- ATTT: **bảo mật hệ thống, mạng, dữ liệu**; KHDL: **khai thác dữ liệu để phân tích, dự báo**.
- ATTT cần **kiến thức mạng, hệ điều hành, mã hóa**; KHDL cần **toán, thống kê, học máy**.
